素材批量搜索判定 · 书签

在「媒体素材(实时)」页面一键批量搜索：把名单粘进去 → 逐个自动搜索 → ✓可搜到 / ✗搜不到 → 结果框列出能搜到的名称，一行一个，一键复制。

1

安装书签

把这个按钮 拖到浏览器书签栏（Chrome / Edge 都支持）：

素材批量搜索判定（拖我到书签栏）

拖不动的话：点「复制书签链接」→ 打开浏览器书签管理器新建书签，把地址粘贴进去即可。

2

使用

  1. 打开 「媒体素材(实时)」页面（素材 → 媒体素材(实时)，需已登录）。
  2. 点一下书签，右侧会弹出操作面板。
  3. 把要搜索的名称名单直接粘贴到文本框（或把 .txt 文件拖进虚线框），每行一个名称，数量不限。
  4. 点「开始执行」，面板逐个自动搜索判定：✓可搜到 / ✗搜不到。
  5. 执行完，结果框列出能搜到的名称，一行一个，点「复制结果」或直接点结果框即可复制。
3

面板说明

  • 试跑1个：只执行第一个名称，先确认判定是否准确再整批跑。
  • 严格匹配首条：勾选后，仅当搜索结果首条素材名称包含所搜关键词才算可搜到（宁缺毋滥）；不勾选时，返回 ≥1 条即算可搜到。
  • 步间隔 / 等待：每次搜索间隔秒数、每次搜索的结果等待秒数（默认都是 1 秒），可按需调整。
  • 判定以页面「共N条」为准：返回 0 条即判「✗ 搜不到」，不会返回给你；只有能搜到（≥1 条）才会列进结果。
  • 诊断：输出当前页面识别情况（搜索框/按钮/卡片数/共N条），有问题时把日志发给我。
  • 面板可拖动标题栏、可折叠（▁）、可关闭（×）、可暂停/终止。
4

注意事项

  • 名单只按换行分隔：名称里的中文逗号/顿号（如「姐们谁管你真假千金，我天生锦鲤好命38」）是一个完整名称，不会被拆开。
  • 不做后缀处理，直接按你输入的内容原样搜索。
  • 首次使用建议先「试跑1个」看日志，确认能正确搜索判定，再整批执行。
  • 面板只在你点击书签的那个页面上生效；刷新或关闭页面后需重新点一次书签。
  • 搜索是平台的实时接口，若某个名称结果一直不变且数量很大，可能是搜索未生效，日志会提示，请留意。
