📜 书签代码转换工具

双向转换：乱码 → 代码 还原成可读的 JS，或 代码 → 乱码 生成可直接粘贴进书签的 javascript: 链接。完全在本地运行。

① 粘贴内容

② 转换结果

怎么用：
1. 乱码 → 代码：把浏览器里复制的那段 javascript:(function()%7B...%7D)()%3B 粘进上方，点【乱码 → 代码】，得到正常 JS 代码。
2. 代码 → 乱码：把 (function(){...})(); 正常代码粘进上方，点【代码 → 乱码】，得到可直接粘贴进浏览器书签地址栏的 javascript: 链接。
3. 自动识别：粘贴内容带 % 编码时点【乱码 → 代码】；纯 JS 代码时点【代码 → 乱码】。
4. 【⇅ 互换上下】把结果放回输入框继续改，方便反复转换。
注意：本工具完全在本地运行，代码不会上传到任何地方，离线也能用。
