# 短剧工作台 · 网页工具集合

本地网页工具集合：全部为单个 HTML 文件，**双击即用，无需安装、无需联网、无服务器依赖**（工具内的自动化书签除外，需在对应网页上点书签使用）。

## 快速开始

- **本地使用**：双击 `index.html`，左侧选工具，右侧直接使用。
- **在线访问**（部署 GitHub Pages 后）：打开 `https://<你的用户名>.github.io/<仓库名>/` 即可，更新代码推送后自动生效，无需再传文件。

## 工具清单

### 素材整理
| 工具 | 说明 |
| --- | --- |
| 素材剧名配对台 | 两行配对（上行素材名、下行剧名），单独一行则同名，分出可复制的剧名/素材名清单 |
| 空行分隔工具 | 多行文本变成每行之间空一行，一键复制 |
| 短剧片名拆条台 | 批量清洗剧名：去 `_` / `-` 后缀、自定义前缀、尾部英文 |
| 剧名素材拆分小工具 | 含「衍生 / - / _」的行判为素材，其余判为剧名，自动分组 |
| 账号格式转换工具 | 混排账号整理成英文逗号分隔一行 |

### 查询与自动化
| 工具 | 说明 |
| --- | --- |
| 查剧名 | 素材名反查短剧名，内置约 9 万条对应关系本地数据库，粘贴即查（无需书签，直接使用） |
| 素材批量搜索判定 | 书签：在「媒体素材(实时)」页批量搜索，✓可搜到 / ✗搜不到 |
| 素材批量下载助手 | 书签：在创量「素材筛选」页批量下载素材（按行分剧名） |
| 视频ID批量选择 | 书签：在「添加素材」页一键批量选中视频ID（每次最多 15 个） |
| 绑剧 | 书签：在快手短剧「我被指派的分销 > 分销短剧」列表批量搜剧名并绑定投放账户 |

### 书签维护
| 工具 | 说明 |
| --- | --- |
| 书签代码转换工具 | 乱码 ⇄ 代码双向转换（浏览器书签里的 `%7B%3D` 乱码 ↔ 正常 JS 代码） |

## 目录结构

```
z/
├── index.html        # 集合页入口（本地打开显示全部；线上只显示公开工具）
├── README.md
├── updates.js        # 更新日志数据（集合页与各工具页感叹号共用）
├── tools/            # 可公开工具（上传 GitHub），共 11 个，双击即用
├── src/              # 4 个书签工具的可读源码（.js，改代码改这里）
├── build/            # 构建脚本（node build.js 把 src 压缩成书签注入 tools 页面）
└── private/          # 本地专用工具：含账号/后端数据，被 .gitignore 忽略，绝不上传
```

> `tools/查剧名.html` 依赖同目录 `data.js`（约 4.4MB 的本地查询数据库，由 `D:\z\大数据库（用于查剧名）\build_db_v1.py` 生成）。要更新数据：在原目录用 build_db_v1.py 重新生成 data.js，再复制覆盖到 `tools/data.js` 即可。

## 书签工具改代码流程（VSCode）

书签工具的实际代码以压缩形式嵌在 `tools/*.html` 里，直接改页面很难维护。统一流程：

1. **改源码**：用 VSCode 编辑 `src/` 下对应 `.js`（带注释、可读）；
2. **构建**：终端运行 `node build/build.js`（只构建单个：`node build/build.js 绑剧`）；
3. **验证**：刷新 `tools/` 对应页面，重新拖书签即可。

> 4 个书签源码：素材批量搜索判定.js、视频ID批量选择.js、素材批量下载助手.js、绑剧.js。页面内其他文字（安装步骤、说明）直接改 `tools/*.html`。

## 部署到 GitHub Pages

1. 注册/登录 GitHub，新建仓库（Public），仓库名建议用英文如 `duanju-tools`；
2. 把本目录内容上传：可网页端拖拽上传，或用 VSCode 的 Git 功能推送；
3. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)` → Save；
4. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。
5. 以后改代码：VSCode 打开本目录 → 修改 → 提交推送，页面自动更新。

## 安全说明

- `private/` 目录存放含账号信息、后端接口、运行日志的工具（书签管理后台、时报采集、时报补录），**仅限本地使用**，`.gitignore` 已排除，请勿手动上传；
- 所有工具代码在浏览器本地运行，不使用本仓库存储任何用户数据。
